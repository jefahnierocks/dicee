# Windsurf/Cascade compatibility note

Read [`AGENTS.md`](AGENTS.md) before working. The rules under `.windsurf/rules/` provide editor-specific scoping only and must remain consistent with that repository authority.

Dicee has no project-managed Windsurf MCP configuration. Follow the "Windsurf and Copilot CLI" section of `docs/MCP-SETUP.md`: copy the documented remote server URLs into your user-level configuration and let the client perform OAuth. Never put tokens in editor configuration.
